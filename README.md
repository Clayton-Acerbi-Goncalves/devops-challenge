# DevOps Challenge

This project contains Linux, Bash scripting, log analysis, and DevOps practice exercises.

## Topics Covered

* Linux commands
* Bash scripting
* Log analysis
* System monitoring
* Git and GitHub
* Nginx logs
* SSH security checks

## Goal

Practice real-world DevOps and Cloud Engineer tasks in a simulated Linux environment.

## Branch Workflow

This repository also demonstrates Git branching and merge workflows used in DevOps teams.
